# Karaduoke 0.4.0 · 使用说明

卡拉OK 现场系统。两种工作模式：

| 模式 | 音源 | 说明 |
| --- | --- | --- |
| **A · YouTube 在线** | YouTube | 无需本地曲库，联网即用 |
| **B · 本地曲库** | 本地文件 | 下载 + Demucs 分离伴奏/人声，支持人声无级调节 |

> **想自己动手部署环境？** 看 `环境部署指南.md`，里面把每一步都拆开讲了。
> 本文只讲「怎么快速用起来」。

---

## 一、这台机器需要什么

| 依赖 | 是否必须 | 说明 |
| --- | --- | --- |
| **Windows 10/11 64 位** | 必须 | |
| **Node.js** | **已内置，无需安装** | 包里自带 `runtime\node\`；如系统已装 20+ 则优先用系统的 |
| **Python 3.12** | **不需要预装** | 控制面板「下载 Python 环境」自动下载 |
| 网络 | 必须 | 首次安装用 |

> **整个安装过程不需要管理员权限，也不会改动系统 PATH 或注册表。**
> Python、torch、demucs、ffmpeg 全部装在本目录里，
> 卸载时直接删掉整个文件夹即可。

## 二、首次启动（3 步）

### 1. 启动控制面板

双击 **`start.cmd`**（推荐，能看到输出）
或 **`start.vbs`**（无黑框）。

**不需要先装 Node.js** —— 包里已经带了一份。

启动后控制面板会在浏览器打开：http://127.0.0.1:8787

首次启动会自动生成 `config\config.json`，里面有一个随机 DJ 密码。

> Node.js 的选用顺序：系统装的（PATH 里的 node）→ 包内自带的 `runtime\node\`。
> 两种都没有时才会提示你运行 `setup-runtime.cmd`（正常包里不会走到这一步）。

### 2. 配置基础信息

面板里点 **「设置」**，建议填写：

- **DJ 密码** —— 主持人登录控制台用，记下来
- **YouTube API Key** —— 模式 A 搜索必需，可在 Google Cloud Console 免费申请
- **Spotify 凭证** —— 仅模式 B 的曲库管理需要，可选

> 两个模式共用这一份配置。

### 3. 安装 Python 环境（只有模式 B 需要）

模式 A 可以跳过这一步。

1. 面板点 **「环境配置」**
2. 点 **「下载 Python 环境」** → 会在项目根生成 `setup-env.cmd`
3. 到项目根**双击 `setup-env.cmd`**
4. 等待完成（约 10–30 分钟，需下载约 5GB：Python + torch + demucs）
5. 回到面板点 **「Refresh」**

看到 Python / ffmpeg / ffprobe 全部变成绿色 **ready** 即完成。

建议再点一次 **「Preload models」** 预热 Demucs 模型，避免第一次点歌时卡很久。

## 三、日常使用

1. 面板里选择模式（A 或 B）
2. 点 **「启动服务」**
3. 点 **「打开大屏」** —— 用独立窗口打开展示页
4. 参与者在手机扫码（大屏上有二维码）后点歌

页面地址：

| 页面 | 地址 |
| --- | --- |
| 大屏 | `http://localhost:3100/display` |
| DJ 控制台 | `http://localhost:3100/admin` |
| 手机点歌 | `http://localhost:3100/join` |
| 曲库管理（仅模式 B） | `http://localhost:3100/library` |

两个模式**互斥**，共用端口 3100（可在设置里改）。

## 四、目录说明

```
Karaduoke\
├─ start.cmd / start.vbs    启动控制面板
├─ setup-runtime.cmd        Node.js 修复工具（正常情况下用不到）
├─ main.js                  统一服务入口
├─ launcher\                控制面板（端口 8787）
├─ runtime\node\            内置的 Node.js（约 90MB，随包提供）
├─ config\                  配置文件（首次运行自动生成）
│  └─ config.json           DJ 密码 / API Key / Spotify 凭证
├─ logs\                    运行日志
├─ karaoke_ytb\             模式 A 工程
├─ karaoke_spo\             模式 B 工程
└─ env\                     ← 首次装 Python 后才会出现
   ├─ python\               虚拟环境
   ├─ python-runtime\       Python 本体
   ├─ cache\                模型缓存
   └─ bin\                  ffmpeg / ffprobe / cloudflared / uv
```

## 五、常见问题

**Q：双击 start.cmd 一闪而过 / 提示缺少 Node.js？**
正常情况下不会出现——包里带了 Node.js。
若真遇到，先确认 `runtime\node\node.exe` 是否存在（杀毒软件可能误删），
再运行 `setup-runtime.cmd` 修复。

**Q：控制面板点「启动服务」报错？**
多为端口被占用。确认没有另一个实例在跑，或到「设置」里换个端口。

**Q：「下载 Python 环境」之后 Python 还是 missing？**
确认你**双击运行了**项目根的 `setup-env.cmd` —— 面板只是生成脚本，不会自己执行。
如果脚本报下载失败，多半是网络问题，重跑一次即可（会复用已下好的部分）。

**Q：模式 A 搜索没结果？**
检查「设置」里的 YouTube API Key 是否填写正确，或配额是否用完。

**Q：模式 B 点歌后一直「处理中」？**
首次制作一首歌需要下载 + AI 分离，约 1–4 分钟。看「曲库管理」里的进度。

**Q：人声滑块没反应？**
只有模式 B 的本地曲目能调。YouTube 音源是混好的，拆不开。

**Q：想换台电脑 / 换路径？**
整个目录复制过去即可。但 `env\` **不要复制** —— Python 环境不可搬移，
在新机器上重新执行「下载 Python 环境」那一套流程。
（`runtime\node\` 可以复制，它是便携的。）

**Q：yt-dlp 需要单独安装吗？**
不需要。项目用的是 Python 模块 `yt_dlp`，`setup-env.cmd` 里已经通过
`pip install ... yt-dlp ...` 装好了，不需要再单独放一个 yt-dlp.exe。

## 六、卸载

直接删除整个目录。系统里没有留下任何东西
（未写注册表、未改 PATH、未装系统级 Python）。
