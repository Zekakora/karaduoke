## 一、部署前须知

### 整个系统由两部分组成

| 部分 | 负责什么 | 依赖 |
| --- | --- | --- |
| **Node.js 服务**（控制面板 + 点歌台 + 大屏） | 界面、队列、播放调度 | Node.js 20+ |
| **Python 流水线**（模式 B 专用） | 下载歌曲、AI 分离伴奏/人声、抓歌词 | Python 3.12 + 一批包 |

**只用模式 A（YouTube 在线）只需要 Node.js**，Python 部分可以完全跳过。

模式 B（本地曲库）才需要 Python。

### 三个关键原则

1. **所有东西都装在项目目录里**，不污染系统环境（不写注册表、不改 PATH）
2. **不需要管理员权限**
3. **卸载 = 删掉整个文件夹**

### 磁盘空间预估

| 项目 | 大小 |
| --- | --- |
| 程序本体 | ~100 MB |
| Python 环境（含 torch/Demucs） | ~5.5 GB |
| 模型缓存 | ~160 MB |
| 每首歌的产物 | 约 10–30 MB |

建议预留 **10 GB** 以上。

### 网络要求

- 装依赖时需要访问：`nodejs.org`、`pypi.org`、`download.pytorch.org`、`github.com`
- 模式 A 运行时要能访问 YouTube
- 模式 B 制作歌曲时要能访问 YouTube / Spotify / 歌词源

> 如果你的网络需要代理，pip 和 uv 都支持通过环境变量 `HTTP_PROXY` / `HTTPS_PROXY` 走代理。

## 二、阶段一：装 Node.js

### 2.1 检查是否已有 Node.js

打开命令提示符（Win+R → 输入 `cmd` → 回车），执行：

```cmd
node --version
```

- 显示 `v20.x.x` 或更高 → **已有可用版本，跳到阶段二**
- 提示「不是内部或外部命令」→ 继续往下看
- 显示 `v18` 或更低 → 建议升级

### 2.2 选择一种安装方式

**方式 A：用项目自带的脚本（推荐）**

在项目根目录双击：

```
setup-runtime.cmd
```

它会：
1. 先检查系统有没有 Node.js
2. 没有就下载便携版到 `runtime\node\`
3. 校验版本号

看到 `Node.js is ready` 即成功。

**方式 B：手动装官方版**

1. 打开 https://nodejs.org/
2. 下载 **LTS 版本**的 Windows Installer（`.msi`）
3. 双击安装，一路默认即可（会自动加入 PATH）
4. **重新打开**命令提示符，再执行 `node --version` 确认

**方式 C：项目里已经有便携版**

发行版 zip 里本身带着 `runtime\node\node.exe`，这种情况**什么都不用做**，直接跳到阶段二。

### 2.3 验证

```cmd
node --version
```

输出版本号即可。

> **注意**：Node.js 的查找顺序是「系统的 → 项目自带的」。
> 所以如果你系统里装了 Node 20+，会优先用它，项目自带的便携版不会生效。
> 这是有意设计的，避免同一台机器上出现两个版本、行为不一致。

## 三、阶段二：装 Python 与依赖

> **只用模式 A？跳过这一整章。**

### 3.1 两种做法

**做法 A：让控制面板生成安装脚本（推荐）**

1. 先按[阶段四](#五阶段四首次启动与验证)把控制面板打开
2. 点「环境配置」
3. 点「下载 Python 环境」
4. 会生成 `setup-env.cmd` —— 到项目根**双击运行**
5. 等待 10–30 分钟

**做法 B：手动逐步执行**（想搞清楚每一步在干什么，或者脚本失败时用）

下面把 `setup-env.cmd` 里面做的事拆开讲。

### 3.2 手动安装步骤

#### 第 1 步：准备 uv

uv 是一个 Python 包管理器，单文件、不需要预装 Python 就能用。

验证系统里有没有：

```cmd
uv --version
```

没有的话，项目脚本会自动下载到 `env\bin\uv.exe`。你也可以手动下载：
https://github.com/astral-sh/uv/releases/latest/download/uv-x86_64-pc-windows-msvc.zip

解压后把 `uv.exe` 放到 `env\bin\` 下。

#### 第 2 步：下载 Python 本体

```cmd
cd /d <项目根>
set "UV_CACHE_DIR=%CD%\env\cache\uv"
set "UV_PYTHON_INSTALL_DIR=%CD%\env\python-runtime"
env\bin\uv.exe python install 3.12 --install-dir env\python-runtime
```

**为什么把 Python 装进项目里，而不是用系统安装的？**

因为 venv 只是个「壳」，本身不含解释器，它靠 `pyvenv.cfg` 指向外部的 base Python。
如果 base 装在用户目录（如 `%LOCALAPPDATA%\uv\python\...`），整个 `env\` 就**无法随项目搬移**。
装进项目内后，`env\` 是一个完整的、可整体复制的环境。

完成后确认：

```cmd
dir env\python-runtime
```

应该能看到 `cpython-3.12.xx-windows-x86_64-none\` 这样的目录。

#### 第 3 步：创建虚拟环境

```cmd
env\bin\uv.exe venv env\python --python "env\python-runtime\cpython-3.12.x-windows-x86_64-none\python.exe" --seed
```

> 路径里的 `3.12.x` 换成你上一步实际看到的版本号。
> `--seed` 表示顺带装上 pip。

验证：

```cmd
env\python\Scripts\python.exe --version
```

应输出 `Python 3.12.x`。

#### 第 4 步：安装依赖包

```cmd
env\python\Scripts\python.exe -m pip install --upgrade pip
env\python\Scripts\python.exe -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/xpu
env\python\Scripts\python.exe -m pip install demucs yt-dlp soundfile numpy requests
```

**这几行分别是什么：**

| 包 | 作用 | 必需 |
| --- | --- | --- |
| `torch` / `torchaudio` | Demucs 的深度学习后端 | 是 |
| `demucs` | **核心**：把人声和伴奏分离 | 是 |
| `yt-dlp` | 从 YouTube 下载音频 | 是 |
| `numpy` | 数值计算（torch/demucs 依赖） | 是 |
| `requests` | HTTP 请求（抓歌词） | 是 |
| `soundfile` | 音频读写 | 可选，当前代码未直接使用 |

**关于 torch 的版本**：

上面用的是 **XPU** 源（Intel Arc 显卡加速）。
- 有 Intel 独显 → 用上面的命令
- 只有 NVIDIA 显卡 → 换成 `--index-url https://download.pytorch.org/whl/cu121`
- 没有独显 → 去掉 `--index-url`，装 CPU 版（能跑，但分离一首歌要慢 3–10 倍）

**可选包**（不影响主流程，按需装）：

```cmd
env\python\Scripts\python.exe -m pip install ytmusicapi spotdl
```

| 包 | 作用 |
| --- | --- |
| `ytmusicapi` | 官方 MV 匹配的免配额候选源；没装会自动退回 YouTube Data API |
| `spotdl` | 优先用 Spotify 元数据匹配下载；没装会自动退回纯 yt-dlp |

### 3.3 验证依赖装齐了

```cmd
env\python\Scripts\python.exe -c "import torch, demucs, yt_dlp, numpy, requests; print('all ok')"
```

输出 `all ok` 即成功。

想看得更细，逐项检查：

```cmd
env\python\Scripts\python.exe -c "import torch; print('torch', torch.__version__)"
env\python\Scripts\python.exe -c "import demucs; print('demucs', demucs.__version__)"
env\python\Scripts\python.exe -c "import yt_dlp; print('yt-dlp', yt_dlp.version.__version__)"
```

### 3.4 预热模型（强烈建议）

Demucs 第一次运行会下载模型权重（约 80 MB）。提前下载好，避免第一次点歌时卡很久：

```cmd
env\python\Scripts\python.exe -c "import demucs.pretrained as p; p.get_model('htdemucs'); print('models ready')"
```

或者用控制面板的「Preload models」按钮。

验证缓存是否落地：

```cmd
dir env\cache
```

应能看到 `torch\` 和 `huggingface\` 两个目录。

## 四、阶段三：配置二进制工具

这些是**可执行文件**，不是 Python 包，放在 `env\bin\` 下。

### 4.1 需要哪些

| 文件 | 用途 | 是否必需 |
| --- | --- | --- |
| `ffmpeg.exe` | 音频转码（yt-dlp 和 demucs 都依赖） | **必需**（模式 B） |
| `ffprobe.exe` | 读取音频元信息 | **必需**（模式 B） |
| `cloudflared.exe` | 内网穿透，让手机从外网访问 | 可选 |
| `uv.exe` | 装 Python 用，装完就不再需要 | 阶段二产生 |

### 4.2 安装方式

**方式 A：控制面板下载（推荐）**

控制面板 →「环境配置」→ 点「Download ffmpeg」/「Download cloudflared」。

**方式 B：手动放置**

- **ffmpeg / ffprobe**：从 https://github.com/BtbN/FFmpeg-Builds/releases 下载
  `ffmpeg-master-latest-win64-gpl.zip`，解压后从 `bin\` 子目录里取出
  `ffmpeg.exe` 和 `ffprobe.exe`，直接放到 `env\bin\`

- **cloudflared**：从 https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
  下载后放进 `env\bin\`

### 4.3 验证

```cmd
env\bin\ffmpeg.exe -version
env\bin\ffprobe.exe -version
```

出现版本信息即可。

## 五、阶段四：首次启动与验证

### 5.1 启动控制面板

在项目根双击 **`start.cmd`**（推荐，能看到输出）
或 **`start.vbs`**（无黑框）。

浏览器会自动打开控制面板：http://127.0.0.1:8787

首次启动会生成 `config\config.json`，其中有一个**随机的 DJ 密码**。
登录控制台需要它，请记下来（也可以在「设置」里改成自己想要的）。

### 5.2 配置基础信息

控制面板 →「设置」：

- **DJ 密码** —— 主持人登录 `/admin` 用
- **YouTube API Key** —— 模式 A 搜索必需。
  到 https://console.cloud.google.com/ 创建项目 → 启用 YouTube Data API v3 → 创建 API 密钥
- **Spotify 凭证** —— 仅模式 B 的曲库管理需要，可选

> 两个模式共用这一份配置。

### 5.3 启动服务

1. 面板左上角选择模式：**A · YouTube 在线** 或 **B · 本地曲库**
2. 点「启动服务」
3. 看到状态变成「运行中」即成功

### 5.4 打开各个页面

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 大屏 | `http://localhost:3100/display` | 投影 / 电视 |
| DJ 控制台 | `http://localhost:3100/admin` | 主持人管理队列 |
| 手机点歌 | `http://localhost:3100/join` | 参与者扫码进入 |
| 曲库管理 | `http://localhost:3100/library` | 仅模式 B |

大屏建议用面板的「打开大屏」按钮，它会带上 `--autoplay-policy=no-user-gesture-required`，
避免浏览器拦截自动播放。

### 5.5 验证清单

- [ ] `node --version` 有输出
- [ ] 控制面板能打开，状态显示正常
- [ ] 模式 A：搜索一首歌能出结果（说明 YouTube API Key 有效）
- [ ] 模式 B：环境面板里 Python / ffmpeg / ffprobe 全绿
- [ ] 模式 B：能点一首歌并播放（首次会显示「处理中」，等 1–4 分钟）

## 六、理解目录结构

```
Karaduoke\
├─ start.cmd                  启动入口（找 Node 并运行控制面板）
├─ start.vbs                  同上，无窗口版
├─ setup-runtime.cmd          装 Node.js 的辅助脚本
├─ setup-env.cmd              装 Python 环境的脚本（控制面板生成）
├─ main.js                    统一服务入口
│
├─ launcher\                  ← 控制面板（端口 8787）
│  ├─ main.js                 面板服务
│  ├─ environment.js          环境检测与安装逻辑
│  ├─ service.js              启动/停止卡拉OK服务
│  └─ ui\                     面板前端
│
├─ karaoke_ytb\               ← 模式 A 工程
├─ karaoke_spo\               ← 模式 B 工程
│  ├─ server.js               服务本体
│  ├─ scripts\                Python 流水线
│  │  ├─ pipeline.py          总调度
│  │  ├─ fetch_audio.py       下载音频
│  │  ├─ fetch_lyrics.py      抓歌词
│  │  └─ ...
│  └─ python\                 曲库数据库相关
│
├─ runtime\node\              ← 便携版 Node.js（若使用）
├─ env\                       ← 运行环境（阶段二、三产生）
│  ├─ python\                 虚拟环境（venv）
│  ├─ python-runtime\         Python 本体
│  ├─ cache\                  模型缓存（torch / huggingface / uv）
│  └─ bin\                    ffmpeg / ffprobe / cloudflared / uv
│
├─ config\config.json         ← 配置（首次运行生成，含密码）
├─ logs\                      ← 运行日志
└─ data\                      ← 运行状态
```

**关键理解**：`env\` 目录是「运行环境」，里面全是可再生的东西。
换电脑时**不要复制它**（Python 环境不可搬移），在新机器上重跑阶段二、三即可。

## 七、常见问题排查

### 启动相关

**Q：双击 start.cmd 窗口一闪而过**

用命令提示符跑，能看到错误：

```cmd
cd /d <项目根>
start.cmd
```

**Q：提示「Node.js is required」**

系统里没有可用的 Node.js，且项目内也没有便携版。
运行 `setup-runtime.cmd`，或者手动装 Node.js 20+。

**Q：改了 Node.js 安装目录后提示 spawn ENOENT**

PATH 里残留了旧路径。新版本已修复（会校验文件是否真实存在），
如果仍遇到，确认用的是最新版程序。

**Q：控制面板点了「启动服务」但一直没起来**

1. 检查端口 3100 是否被占用：

```cmd
netstat -ano | findstr :3100
```

2. 看 `logs\launcher-*.log` 里的错误
3. 面板「日志」区域也会显示服务的 stderr

### Python 相关

**Q：报错「Python 环境未就绪」**

```cmd
env\python\Scripts\python.exe --version
```

看是否存在。没有的话重跑阶段二。

**Q：pip 报错「No module named pip」**

```cmd
env\python\Scripts\python.exe -m ensurepip --upgrade
```

**Q：装 torch 卡住 / 超时**

XPU 版体积很大（约 2 GB）。可以先装 CPU 版验证流程通不通：

```cmd
env\python\Scripts\python.exe -m pip install torch torchaudio
```

确认能跑通后，再装 XPU 版覆盖。

**Q：点歌后一直「处理中」或者失败**

1. 确认 ffmpeg 在 `env\bin\`
2. 看控制台「曲库管理」里的错误详情
3. 手动跑一次流水线看报错：

```cmd
env\python\Scripts\python.exe karaoke_spo\scripts\pipeline.py --help
```

### 运行相关

**Q：YouTube 搜索没结果（模式 A）**

- 检查「设置」里的 YouTube API Key
- 到 Google Cloud Console 看配额是否用完（免费额度每天 10,000 单位）

**Q：人声滑块没反应**

只有模式 B 的**本地曲目**能调。YouTube 音源是混好的音频，拆不开。

**Q：手机扫码打不开**

- 确认手机和电脑在同一个局域网
- Windows 防火墙可能拦截：允许 Node.js 通过专用网络
- 需要外网访问时，启动 cloudflared 穿透
